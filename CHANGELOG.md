# Changelog

## 1.0.7

The map release. Nova can now build a whole new world for a mod from one button, and the map tools were worked through one at a time, then together on one generated world, with Auto-fix closing the gaps between them. Worlds Nova generated were played on 1.19 for up to two years of game time without a crash, and one generated by this release ran on 1.20 for over four months of game time without one.

If you are upgrading from 1.0.6, the short version: **the map editor says what the game will actually do, and nothing Nova replaces is thrown away.** Map Errors no longer calls a problem a crash when shipping maps or launches show the game loads past it, and Auto-fix no longer repairs a problem the mod only inherits from another mod or the base game. What a Restore baseline or a new baseline replaces is moved out of the way instead of deleted, and so is an earlier Remove country archive. And Nova stops leaving its own copies inside your mod, where they went up to the Workshop with everything else.

This release is made for Hearts of Iron IV 1.20, "Operation Postern".

---

### ⚡ Hearts of Iron IV 1.20

- **Re-checked on 1.20.0.0.** Nova's map rules, readers and engine checks were gone through again against the new game. The base game raises no fatal map problem, no rule's count on it moved from 1.19, and a fresh mod over it shows no Mod Health problems. On 1.20, a test run of the chain Generate a world runs — Delete map, Generate land, Auto-fix all, Redraw regions — ended with nothing in Map Errors and nothing left for Auto-fix.
- **A mod made for another game version is a warning, not a crash.** A mod whose descriptor says it supports 1.19 now gets an amber note in Mod Health's "Will it crash?" card, with the advice on rolling the game back, instead of a red "fix this before launch". The version banner on every page and the Map editor's box are amber too. A real fatal map problem still turns the card red on its own.

### 🗺️ Map editor — a world from one button

- **Generate a world** (new) builds a whole new world for the mod in one go. It makes the map the mod's own — its own province map, and `replace_path = "history/states"` in the descriptor so the base game's states stop loading underneath — then runs Delete map, Generate land, Auto-fix all, Redraw regions and Map Errors. A panel follows each step in the words of that step's own button, other writes to the mod wait until it is done, and the dialog says up front how long it takes: about five minutes for a first world, longer when the mod has been generated before. It is on the map page, and it is offered when you create a new mod. It refuses an add-on whose base mod is not installed, and a "One country" world for a tag no country has.
- **Generate land grows continents instead of scattering islands.** On one test world it raised 847 separate landmasses, 662 of them a single province; now almost all of the new land sits in large masses of ten provinces or more. States are grown from whole regions, and terrain follows the base game's own mix for each height, weighted by latitude.
- **A generated world looks like a world.** Relief and beaches climb the way the base game's do, coasts are rough rather than ruled, terrain and trees follow latitude, and rivers are drawn once the coast and heights are final — the worlds generated before had none. Cities and towns stand at victory points, lit at night, and every capital is a city. The ground textures and the minimap are repainted, and the colour-grading boxes over ground that changed are taken out, so the old Earth no longer shows through the new world and the land no longer looks like glass.
- **…and plays like one.** Generate land asks who owns the new land: the countries of the world below it, one country, or nobody. Given to the countries below, each country that held land keeps some — on the base game and the big mods it was tried on — with its capital on the most important state its army can reach, and its 1936 factories, dockyards and people as far as its new land has room for them. State ids keep their meaning, so cores and claims still point where they should. Armies are moved onto their own country's land, fleets are berthed, air wings are based where their country holds the state, and navies get harbours. Ports face the sea, harbours sit on ground the game draws, and supply hubs and railways join the land up, with the track steered away from bays.
- **Places have names.** States and regions get made-up place names, checked against a list of slurs and obscenities, in every language the game ships, and every state has a victory point. If a fatal problem is still there at the end, Generate land runs Auto-fix all's repair before it finishes.
- **Delete map** refuses a world the mod does not own, and clears what stood on the land along with it — rivers, forests, night lights, supply hubs and railways — instead of leaving them at sea. It takes the capitals out, including the capital lines in the mod's own country files, and says so; it says what it cannot blank and which file to edit instead; it keeps a copy of every file it overwrites; and it gives back the provinces an earlier Generate land cut.
- **Redraw regions** (new) draws the strategic regions for the land and sea the map has now: land regions from whole states, sea regions from the sea, and a lake the ocean surrounds made sea. Its plan is refused unless it passes the engine's own rules. It keeps the regions' translations and your comments, a second press keeps the names the first gave, and a redraw that fails undoes itself. A new Map Errors warning says when a map's regions ignore its coastline.

**Fixed:** **every world Nova had ever generated had no owners.** Generate land took one country tag for the whole planet and its dialog never sent one, so on one launch 832 states had no owner, the game wrote 166,849 lines to its error log, and it crashed two game-weeks in. Also fixed: generated states with no name of their own, which the game showed as a raw key, and regions still carrying Earth's names over a new world.

### 🗺️ Map editor — the tools

- **Country card** (new). Select a country and see what the game gives it on day one: its focus tree — with a warning when that is the generic tree or a shared one, naming the DLC it needs — its laws, national spirits, capital and land. From the card you can open its focus tree, its research, Country Setup or its army.
- **The map's country pickers offer the countries the game loads.** An add-on over the base game was offered 50 dynamic placeholder tags and not offered 108 of its 364 real countries. The eyedropper and links into the map pick only countries a picker offers, and a new check reports land given to a civil-war tag.
- **Painting.** A shape stroke raises land the way Generate land does; the brushes act on the pixel the readout under the cursor names; a big Erase or Terrain brush takes every province under it; a coast painted out and back is put back where it stood; a paint that cuts a sea off from the ocean says so; and a paint or Move that is refused takes back out the state file it had copied into the mod.
- **Erase** sinks the land it turns into sea, cuts more than one province deep, and now also takes the rivers and strategic locations on that land along with its buildings, victory points, supply hubs and railways, writing a whole stroke in one request. A Move or Erase that would take the last land out of a state the base game defines is refused.
- **Move province** carries everything with it: every building, including those in nested and dated blocks; its victory points, into their dated blocks with their comments; its modifiers and its name. It refuses to move a sea province into a state and counts a lake as no land, and a state the move leaves empty is merged into the one that received the province, with its people, resources and buildings — except a country's capital and a state from the base game, which are kept and named.
- **Terrain brush** offers the mod's own terrain types, paints the city look, and grows what that terrain grows.
- **Rivers.** The source marker is now drawn on the rivers overlay, and a river cut off from its source is reported, with an Auto-fix.
- **Railways and supply hubs.** A click on the sea, or on a province with no state, is refused at the click instead of at Save, and so is a link the game would drop; one already in the file is reported, and Auto-fix splits the railway there. Changing a level is one write, levels go up to the mod's own maximum, and removing a hub or railway leaves your comment lines in place. A railway row with a comment after it is read, a file that holds only comments counts as empty, and the empty-file warnings quote the base game's own railway and hub counts, read from your installed game.
- **Adjacencies.** Canals can be drawn; a strait through a province needs that province to exist; Auto-fix retypes an adjacency that a province type change broke, never deletes it, and leaves the rows you wrote alone; the file keeps its encoding; a link written as two rows stays together on the page; and Map Errors warns about link shapes no shipping map uses.
- **States.** A new state gets building slots, an air base site and a name the game shows. A victory point you add says when nothing names it, and gives the localisation key to add. Typing a core changes only that core. Population 0 is written as 1, and the panel now shows and says so. A naval base is held to the province's maximum, and one already over it can be lowered. An empty state name is refused, state categories are offered from the categories that load, and the Owner box warns about a capital the way a paint does.
- **Countries.** A new country gets the technology, government, ideologies, flag and names the game loads, whichever of the three creators you use, and is declared where the game treats it as a real country rather than a civil-war tag. A create that cannot take every state you gave it still finishes, and names the ones it could not take. Set capital writes a capital the game reads, and says which file it copied into the mod.
- **The Army tool** gained Undo for placing and removing divisions, keeps unsaved army work through a reload, refuses a fleet placed on land with no sea beside it, offers to re-read a file that changed on disk, and no longer saves the old world's order of battle over a new one. It opens beside the dock on its own key, O, unless you have given that key to something else.
- **Saving and keys.** Only one Save runs at a time; Ctrl+S works from a text field; a key pressed under a dialog no longer reaches the map; the History panel says it keeps 30 steps; a slow drag counts as a drag; the page names every button that writes straight away rather than on Save; the Keys reset names the keys it resets; and copying and pasting a state's attributes says what it cannot carry.
- **The notice when you open the Map editor** no longer says it is still in development. It asks you to back up your mod and its .mod file first, since Nova keeps only its newest backups, and to build on a map that already loads in the game, because Auto-fix all may not be able to fix a map that is already broken.

### 🗺️ Map Errors, Auto-fix and the Save gate

A validator must not cry wolf, and must speak up when the game will fall over.

- **"Will crash" now means it.** Thirteen map problems stopped claiming a crash that shipping maps disprove or the evidence does not show — supply areas, which the game no longer reads, among them. A missing capital stops Save only for a country that has land, and a strategic region crossing the map's left and right edge is judged as one piece.
- **Save stops for more problems than before**, where the game refuses to load or has crashed: among them a land province with no state, a province with no strategic region, a sea region in pieces, a script that names a state the map no longer has, and a fleet that starts on land with no sea.
- **The Save gate says what it knows.** For each problem it stops Save for, it says whether the game refuses to load, has crashed on it, or has never been tried with it.
- **New checks** for what the game does trip on: bitmaps of the wrong size; colours the province definitions do not list; railway rows the game skips; a port facing a lake or no sea at all; buildings over water; a fleet or division left where the map took its sea or land away; an air wing in a state that is gone; a state that owns only water; states named in scripts and AI strategies that a shrunken world no longer has; a province building above its maximum; a lone sea nobody uses; and replaced map files that are missing.
- **Auto-fix all settles in one click, and says what it did**: every step in its summary, why a step failed, which files it copied into an add-on and which it created, and where its copies of the originals are — including that copying them back does not remove the files it created. It fills a cut-off sea only when the mod made it, makes a cut-off lake a lake again rather than land, clears an empty state that only countries with no land name as their capital — a fatal problem nothing could clear before — raises a state with more buildings than slots to a category that holds them, and its toggle says the one thing it decides.

### 🧩 Add-ons and base mods

- **An add-on is judged against the layers below it, in load order.** Map Errors no longer reports to an add-on the problems that belong to the mod beneath it.
- **Auto-fix keeps to the mod you are editing.** It once wrote into a Workshop dependency's map; it no longer repairs another mod's files, and on an add-on with no problem of its own it does nothing — one click on an add-on with no map of its own over Millennium Dawn used to write 34 files, 43.6 MB. When a repair does have to copy a file from below into your add-on, it names the file.
- **A mod that replaces the map folder is judged by its own files**, and a commented-out `replace_path` line is ignored.
- **Mod Health resolves references with `replace_path` in mind**, and says when `replace_path` is why something is missing. A declared dependency whose name is one character out resolves to nothing, which used to turn every reference into that mod into a false error; Mod Health now says so.
- **A mod named "Vanilla Plus" is a mod.** The makers no longer treat it as the base game; 1.0.6 fixed that for the crash checks only.

### 🛟 Backups, baselines and recovery

- **Every write that changes a map file is backed up first, and a map Save keeps the first copy of every file it changes** — through a crash too: a Save that died partway used to lose the copies of 68 of its 152 files. A painted shape is kept for crash recovery, and the recovery bar says plainly what it holds.
- **Save baseline no longer destroys the baseline it replaces.** It used to delete the old one before the new copy was complete, so a full disk or an antivirus lock could leave you with neither, and nothing said so. The old baseline is now moved into a dated folder beside the new one, never deleted. A baseline of a map Save would refuse is refused itself. When Nova has found the game, the map is checked against it as the baseline is saved, and only a baseline whose check passed is called known-good; without the game, the baseline is saved unchecked and says so.
- **A baseline holds more of the map**: the states' names, the region names, armies and fleets, the descriptor's `replace_path` lines, the minimap and the colour-grading boxes. A baseline is found again after the mod's folder moves.
- **Restore baseline moves, never deletes.** It used to swap the baseline in and delete the folders it replaced, so anything you typed by hand after the baseline was saved was gone. Each replaced folder is now moved out of the mod into Nova's own store, one dated folder per restore, and the page says where ("MOVED out of your mod (not deleted) to: …"), names any folder it could not move, says what a restore that stopped partway had done, and reads the map back afterwards. An older baseline without the armies, fleets or descriptor lines is restored with a note saying what it leaves.

### 🔒 Writing to your mod

- **Nova will not write into a folder nobody chose**: the top of a drive, or Nova's own folder. The game's own user folder — where it keeps its settings, saves and mod list — is refused as a mod, wherever the launcher has put it.
- **The mod list is the launcher's.** Nova reads the same mod files the launcher reads, so it lists the copy of a mod the game will load, and refuses a copy the launcher never loads — one left in a second Documents folder, for instance.
- **Workshop downloads are read-only to Nova.** Saves, imports and the flag and newspaper tools all refuse a subscribed Workshop item, and say why, before anything is written.
- **Nothing backup-shaped ships with your mod.** A map edit used to leave a .bak copy beside the file it changed, inside the mod, where it went up to the Workshop with everything else. The real backup was always made in Nova's own store as well, and the extra copy is gone. Remove country's archive — the only copy of the states and history files it overwrites — now lives in Nova's store too. Archives an older Nova left inside the mod are carried out on the next Remove or Restore, each copied, read back and compared before it leaves, never deleted; and removing a country again sets the earlier archive aside instead of writing over it. A region move's backup left the mod as well.
- **Importing a national spirit's picture backs up the picture it replaces**, and refuses to go on if that backup fails.

### 🩺 Mod Health

- **Fix all writes each file once.** It used to back up and rewrite a file once per problem, so a mod with many fixes in a few files could push older backups out of Nova's backup store. Now each file is backed up once.
- **Fix all covers more problems with exactly one right answer**, offline and backed up first: a tooltip key with no text; a localisation key defined twice with identical text — only identical, since nearly half of real duplicates differ, and choosing between those stays with you; an unclosed quote in a localisation line; and an event namespace used without `add_namespace`.
- **A localisation key is a duplicate only under the same language heading.** The base game's language file lists the same ten keys once under each of its ten language headings, which Mod Health reported as "defined 10 times" in any mod that copies the base game's localisation folder. It no longer does, and Fix all's new duplicate-key repair leaves them alone.
- **References resolve the way the engine resolves them**, a hyphen in an id included, so a reference the game accepts is no longer reported as broken.
- **New reports**: the same localisation key defined in two files, where the game's choice between them is not predictable; a focus icon whose sprite nothing declares — the game draws a question mark there, while Nova's editor shows a placeholder; and a typo in `remove_ideas`, as one in `add_ideas` already was.
- **The AI fix is refused when the model's answer changes more than a small edit should** — over 1,500 bytes or 2% of the file, either way; it used to be refused only when the file lost half its size. Fix buttons were withdrawn wherever they could not help, a mod kept inside the game folder is still judged as a mod, and a copied report is capped so it can be pasted.
- **Nameless advisors and hidden ideas are no longer "missing a name".** About 1,270 of the base game's advisors, and about 940 of its old-style advisor ideas, have no name text of their own and are named by their trait, and the ideas in its hidden category are never shown. Mod Health stops reporting them, and Fix all stops writing made-up names for them. An advisor whose trait has no text, and a nameless general, are still reported.
- **Two messages say what the file says.** A broken reference names the call its file writes — `news_event` or `focus_progress`, for instance, where it used to say `country_event` or the name of Nova's own reader — and an event option the game can never show, because its trigger is `always = no`, is no longer reported as nameless.

### 🌳 Focus trees

- **Genesis View (Code-to-English) says what the script says.** It exists so a non-programmer can read a focus or a decision back as a sentence, which makes a wrong sentence worse than none. It dropped `if` and `limit` blocks, and read `has_civil_war = no` — the usual way to write "only while this country is stable" — as "is in a civil war". It now also reads `check_variable`, `all_of`, `any_of`, `count_triggers`, random odds and `else_if` ("otherwise if").
- **A focus file one closing brace short is read the way the game reads it**, instead of losing that tree and every tree after it in the file.
- **The focus page opens the right tree.** Choosing the base game opens its default focus tree: the page used to treat the base game as a mod, open a style file as an empty tree and offer to copy the generic tree into the game folder. A mod whose first focus file is a title-bar style file — Novum Vexillum, Old World Blues and Hearts of Minecraft ship one — opens at its first real tree instead of as an empty one. And a tree remembered from another mod whose folder name starts with the chosen one's (my_mod_dev beside my_mod) no longer opens in its place and switches the mod.

### Known issues

- **A prerequisite written after another on the same line is not seen.** A focus written as `prerequisite = { focus = A } prerequisite = { focus = B focus = C }` means "A, and one of B or C", but Nova does not see the second section, so the editor shows no link to B or C, and saving the tree can write them back as three separate requirements. A few focuses in Hearts of Minecraft are written like this. It is deliberately not fixed in this release, because the fix touches the code that rewrites focus files. Putting each `prerequisite` section on its own line avoids it.
- **Country Setup's National spirits list misses some starting spirits.** It lists only spirits written as `add_ideas = { … }` before the first dated block, so the starting spirits of the base game's Germany and USA, and of nearly every Millennium Dawn country, do not appear there. The Country card on the map shows them.
- **Nova's records of a mod follow its folder.** After you move or copy a mod's folder, Restore country lists none of the countries removed before (their archives stay on disk), and Generate land no longer treats those countries as removed. Removing a country that is already removed sets its earlier archive aside, where Restore country does not list it; Restore then brings back what the second removal archived.
- **Nova never clears out the copies a long map Save keeps.** When a map Save is too long for the backup store, the first copy of every file it changed is kept in a folder in Nova's own data folder. These grow with every such Save, session after session, and nothing deletes them for you.
- **What an older Nova wrote stays where it wrote it.** This release refuses to write into Workshop downloads, but earlier releases could, and what they wrote stays until Steam replaces the item: unsubscribing and subscribing again gets a clean copy. The .bak files an older Nova left inside a mod are not removed either; delete them before you upload.
- **A mod with its own pre-1.20 buildings file** does not have the two rows 1.20 added to the base game's — a landmark and a dam — and Nova does not warn about it. What the game does then has not been tried.
- **Terrain brush:** giving a province a terrain and then its old terrain back does not restore what the first change replaced. The Save line says how many pixels of ground and blocks of trees were replaced, and Nova's backups hold the files as they were.
- **The first page to show the game's pictures can freeze for a few seconds.** The first time in a session that Nova needs the game's sprites — on the National spirits page, for instance — it reads them all before answering, and the window does not respond meanwhile: about 12 seconds on the test machine. It is quick after that.
- **Generated worlds are a starting point, not a finished map.** The base game's own scripts name some states and provinces by number, and on a generated world those numbers point somewhere else, so the game's error log gains lines from them — over 600 from a single script on one test world. A few harbours can sit offshore and a few railway curves cross bays, and generating again in the same mod can leave divisions abroad and lakes behind.
- **Some shapes are reported but do not stop Save, because nobody knows what the game does with them**: adjacency links no shipping map uses, a province building above its maximum, and land owned by a tag declared after `dynamic_tags = yes` (listed as an error, but it does not stop Save).
- **A mod that replaces the whole map folder:** Map Errors and Auto-fix judge it by its own files, but a few of the manual map tools have not been checked against such a mod and may still read the base game's map files beneath it.

## 1.0.6

The makers release. Nova gained a complete Military maker, a research tree that draws what the game draws, and two months of hardening across every editor — most of it driven by playing the mods Nova produces and reading HOI4's own `error.log`.

If you are upgrading from 1.0.5, the short version: **saving something no longer risks it.** A large share of the work below is one bug class — an editor that read part of a file, rewrote the whole thing, and quietly dropped what it did not understand. Comments, DLC gates, `@variables`, nested blocks, accented text, byte-order marks and un-modelled script now survive a round trip.

---

### ⚔️ Military — a new maker

An entire tab, built from nothing this release. It covers the parts of a mod that decide what an army actually is.

- **Division Template Designer**, rebuilt 1:1 against the in-game designer: the real support/regiment grid, the game's own placement rules, drag battalions between slots, and per-battalion stat editing.
- **Equipment & the Arsenal.** Every country's equipment variants are scanned and listed — not just your mod's. Edit any of them in place, create new equipment families, and see the real in-game art, category icons and DLC badges.
- **The modular designer**, mirroring the game's: pick a chassis, fill its module slots, save a variant. Module count-limits and duplicate rules are enforced the way the game enforces them, and the vehicle picture sits above the modules as it does in-game.
- **Custom modules** — author the guns, engines and armour parts themselves, with an in-designer editor.
- **Custom equipment upgrades** — define the XP upgrades a designer can spend on.
- **Weapon creator** — a front door for a brand-new weapon that does not make you start from an existing one.
- **Manufacturers (MIOs)** — create and edit Military Industrial Organizations in-app, with a trait tree, a mod-aware trait picker, and a "Designed by" view that shows the one company the game actually ties to a variant.
- **Companies** — a dedicated maker for designer companies, rebuilt on Nova's design system and editing the real MIO companies that appear in-game.

## 1.0.5

The research-tree-and-map hardening release.

### Research tree
- **1:1 fidelity** — the editor now renders any mod's existing research tree exactly as the game does. Fixed a real bug where commented-out `@variable` redefinitions (e.g. `#@1945 = 18` over the active `@1945 = 2`) leaked into the position parser and misplaced a handful of air techs. A new regression test (`test-research-fidelity.js`) asserts all of Millennium Dawn's ~916 techs land at the exact right spot.
- **Configurable year labels** — a "🔢 Year labels" toggle repeats each year along its guide line: 1 (one end), 2 (both sides), or 3–4 (evenly spaced), so the year stays readable in a tall tree. Per-mod.
- **Folder backgrounds** — a "🖼 Background" toggle shows each folder's real in-game background art, and "🖼 Set bg…" lets you upload your own picture for a folder (written into the mod + the folder's background sprite overridden, so it shows in-game too).
- **Text placer** — "📝 Add text" drops free-text labels on the tree (drag to move, double-click to edit, right-click to delete), persisted per mod. (Editor annotation; rendering the text in-game would require the mod to own a full copy of the research GUI — available as an opt-in on request.)

### Map editor
- **"Still in development" notice.** Opening the Map editor now shows a one-time-per-launch heads-up that the map tools are under active development and not yet fully tested, recommending you back up first and hold off on important work for now. (Dismissable; returns on the next launch.)
- **Hardening** — a seeded fuzz harness drives random map operations and verifies the map stays launchable after each. It found and fixed a gap where creating a state without a category could produce an invalid (un-launchable) state; new states now always get a category. Confirmed the land→sea ("make water") conversion correctly re-files new sea into its naval region. Combined with the existing per-operation Auto-fix and the live "Map Problems" panel, an editor operation can no longer silently corrupt a mod.

### Map crash-proofing
Repeated in-game stress-launches drove a deep pass on the things that make HOI4 refuse to load a map. Nova's Auto-fix and "Map Problems" panel now detect and, where safe, repair the full catalogue of detectable map errors:
- **Restore-baseline backstop** — "💾 Save baseline" snapshots a known-good map; "🛟 Restore baseline" puts it back with one click. This is the absolute "always launchable" guarantee underneath every in-place fix: if anything ever slips through, you're one click from a working map. The Restore button pulses when errors remain after Auto-fix.
- **New fatal-error detection** straight from the wiki: a provinces.bmp that isn't 24-bit or whose size isn't a multiple of 256, gaps in the definition.csv province ids, a province defined but painted out of the bitmap entirely, provinces under 8px or with pixels scattered across the map ("too-large box"), a UTF-8 BOM in adjacencies.csv (auto-stripped), and an empty buildings.txt — verified to produce **zero false positives** on real Millennium Dawn and vanilla.
- **New auto-fixes** for the crashes that survived earlier passes: invalid X-crossings in provinces.bmp, empty states (fatal, were treated as cosmetic), naval strategic regions "fractioned" by a cut-off coastal-land member, stateless land — now including isolated **islands** (homed to the nearest state) — and an empty state left behind when a country's capital is relocated off it. One "Auto-fix all" is now complete in a single pass.
- **Verified against the real game.** Launching a deliberately-corrupted Millennium Dawn and diffing HOI4's own `error.log` against Nova confirmed Nova detects every fatal map-error class the game reports — with matching province/state IDs. The comparison also caught and fixed the last detection gap: fractioned-region checking now uses the game's exact rule (a region is naval if it contains sea, and `adjacencies.csv` sea-straits count for contiguity), so Nova flags precisely what the game does.
- **Hard Save gate for guaranteed crashes.** If a Save leaves the map with an error that is *certain* to crash HOI4 (an invalid map definition, or an empty / dangling-capital state), the popup becomes a wall you can't click past — it shows plain-English "fix it yourself" steps for each one, and to keep a knowingly-broken map you must literally type the word **save**. It fires only when a crash is certain (never on the things the game logs but loads past, and never on warnings), so it's a real stop sign, not noise you learn to ignore.

### Add-ons
- Creating an add-on (a mod that depends on another, e.g. a Millennium Dawn submod) is now a clear up-front choice: the Create Mod dialog and the Home-page storyline wizard both ask **Standalone vs Add-on**, revealing a base-mod field only for add-ons.
- An add-on's inherited icons (focus, idea) and shared focus trees now resolve and position correctly from the base mod.

### Editing safety — delete now cleans up localization
Deleting an item used to leave its **localization** (the name + description text) orphaned in the `.yml` — harmless in-game, but it cluttered the mod and could leave a stale name behind. Fixed across the board: deleting a **national spirit / idea**, a **focus**, a **technology** (and its equipment), or a **continuous focus** now also strips that item's loc, in whichever loc file it lives. (Events, decisions and characters already did this.)

### Research tree
- **No more digit-leading tech IDs.** The editor accepted a technology ID starting with a number (e.g. `1infantry`), but HOI4's parser rejects an identifier that starts with a digit — saving one broke the entire technologies file. The editor now refuses it (must start with a letter or underscore) with a clear message, and the server guards it too so a bad ID can't reach disk.
- **"Hidden techs" toggle.** Marking a tech *Hidden* (`allow = always no`) made its node vanish from the canvas, recoverable only via the search box. A new 🙈/👁 **Hidden techs** toggle draws hidden (and DLC-gated) techs dimmed so you can find and edit them, without changing what saves to disk.
- **The research-screen GUI is now backed up before any edit.** Creating, syncing, or deleting a custom research folder rewrites the mod's `interface/countrytechtreeview.gui` — the file that *is* the in-game research screen. Unlike the makers, those edits were the one write path that did **not** snapshot the original first, so a bad edit could leave the research screen unrecoverable (with no original to diff or restore). Every such write now backs up first. Also fixed the backup pruner, which sorted by file mtime: because a file copy inherits the source's timestamp, a backup of a long-untouched file was "born old" and could be discarded the moment it was taken — it now orders by true creation time, so a just-made backup is never the one pruned.

### Country setup
- **Stat boxes show the country's real starting values.** Stability, War Support, and Research Slots used to sit blank for almost every country, because only a handful of countries script those values — the rest inherit the game's defaults. The boxes now fill with the country's explicit value when it has one, otherwise the *effective* default read from the active mod's defines (e.g. Millennium Dawn raises default stability to 65%), so you can actually see where a country starts. Default-filled values are shown muted (vs. a normal entry for an explicitly-set one) and are never written to the country file unless you edit them.
- **Starting-units panel collapses.** The read-only Order-of-Battle viewer (division templates, divisions, stockpile) can be very tall — 140+ divisions for a major — so it's now collapsed by default behind a one-line header; click to expand, and the choice is remembered.
- **The flag panel now previews a country's current flag.** Selecting a country shows its existing flag instead of an empty box. HOI4 flags are `.tga` (which browsers can't render and the image libraries can't decode), so Nova hand-decodes the country's `gfx/flags/<TAG>.tga` — active mod first, then the base game, falling back to an ideology variant — and serves it as a PNG. Countries with no flag yet show a "no flag yet" hint.
- **Country flag upload.** A new "🏴 Country Flag" panel sets a country's flag from a normal **PNG or JPG** — Nova writes the HOI4 `gfx/flags/<TAG>.tga` at all three sizes (82×52, 41×26, 10×7) plus the per-ideology variants, so a country you create has a real flag from game start instead of a blank placeholder. (Previously the only way was a detour through a focus's cosmetic-tag effect.)
