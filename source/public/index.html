Focus Tree Controls

          
        

        

          

            
Arranging focuses

            
Open a tree with Load, drag focuses where you want, then click Save when you are happy with the layout.

          

          

            
Saving and closing the tab

            

              Use Save (or Autosave when it is on) to write changes to disk. If the tree still has
              unsaved edits and a save is not in progress, the browser may show a warning when you close or refresh the tab
              (the exact message is up to the browser).
            

            

              Autosave only runs when validation passes, no blocking dialog is open, and pending name or description edits have a
              localization file target — hover the Autosave checkbox for details when something is paused.
            

          

          

            
Selecting several at once

            
Click and drag on empty space to draw a box around the focuses you want.

          

          

            
Refining the selection

            
    
              
  • Single click a focus to select only that one.
    • 
              
  • Shift + click or Ctrl + click to add or remove a focus from what you already have selected.
    • 
            

          

          

            
Moving around the map

            
    
              
  • Pan: hold the right mouse button and drag on empty space.
    • 
              
  • Clear selection: a quick right-click on empty space (without dragging) clears the selection.
    • 
            

          

          

            
Zoom

            
    
              
  • Z zooms out, X zooms in (same as the − / + buttons).
    • 
              
  • Ctrl + − zooms out, Ctrl + + zooms in.
    • 
              
  • Ctrl + 0 resets zoom to normal (100%).
    • 
            

          

          

            
Undo, redo, Escape

            
    
              
  • Ctrl+Z undoes. Ctrl+Shift+Z or Ctrl+Y redoes.
    • 
              
  • 
                This editor also maps Ctrl+X to redo (not “cut” to clipboard). Use
                Ctrl+C / Ctrl+V for copy and paste in text fields.
              
    • 
              
  • Escape closes the right-click menu, open dialogs, and prerequisite / mutually-exclusive link modes.
    • 
            

          

          

            
Toolbar height

            
Drag the thin bar under this panel (above the tree) up or down to give yourself more or less room for the map.

          

          

            
Effects and details

            
Right-click a focus to open the menu. Under Effects, use the search field to filter commands; Open focus tree file opens the loaded .txt in Notepad for hand-editing (reload in the editor after you save there).

          

          

            
Prerequisites (must finish before this focus)

            

              In Hearts of Iron IV, a prerequisite is always on the later focus: it lists which earlier focuses must be completed first. The editor matches that: right-click the focus that should wait (the dependent one),
              choose Requires earlier focus…, then click the focus that must be done before it. The dashed line runs from your focus while you choose; saved arrows run parent → child like the game tree.
            

            

              Use Remove requirement… when this focus already has requirements, then click the earlier focus you want to unlink.
            

          

          

            
Debugging

            
Expand Debug / error log in the toolbar. Use Copy report to copy diagnostics, a JSON session snapshot (paths, selection, pending edits, flags), and the log — paste into Cursor or an issue. URL hints: ?debug=1 opens the panel, ?debugVerbose=1 turns on verbose logging.
