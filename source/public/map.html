Loads the base game + your mod's states. 🌍 Generate land
Turns part of the ocean into land and wraps it in states. The land it raises joins the world that is already there: for a whole new world, use 🌍 Generate a world instead. This writes to your mod immediately, then checks the map the way 💾 Save does and reloads.
⚠ This map already has 0 land provinces. Generate land is meant for a blank ocean canvas — running it on a populated map (like Millennium Dawn) adds land into the seas and spins up many new states, which can leave the map a mess. For a whole new world, use 🌍 Generate a world instead: it clears the old world first. To proceed anyway, type GENERATE below.

🗺 Redraw strategic regions
🚚 Move country — ⚠ experimental
This physically moves the country's province shapes on the bitmap and overwrites whatever is at the destination — provinces it covers can be left broken (under 8px / 0px), which HOI4 may refuse to load. It writes immediately (not staged). Province shapes can't be cleanly relocated in HOI4 — that's why this is experimental.
⚠ Turn off Auto-fix?
Auto-fix decides one thing: what happens to a state you empty with ↔ Move province or 🧹 Erase. With it ON, the editor deletes that state for you — HOI4 will not start a game with a state that has no provinces.
With it OFF, an emptied state is left as it is and the editor only warns you: you'll have to ↶ Undo the edit that emptied it, or after 💾 Save use ⚠ Map Errors' 🔧 Auto-fix all, before the mod will load. Everything else works the same either way — a Move still takes a coast's dockyards with its last coastal province, a Move still asks whether to keep the state in one strategic region, and 💾 Save still drops a new state nothing was put in.
