Maintenance

Nova caches icons, sprites and localisation in its own folder so it loads fast. These caches never touch your game or mods — they only affect what this app displays. If you verified game files or changed a mod and Nova still shows the old icon/name, clear the cache to force a fresh read. (Your API key is never affected.)

🔬 HOI4 Diagnostics

Launch Hearts of Iron IV, let it fully load or crash, then click below. Nova gathers every game log and the latest crash dump (incl. the crash's exception + stack trace, which the normal logs don't show) into one report — so you can paste it here for a real diagnosis instead of guessing.
